# План: веб-приложение «Карты обмера» (мультиагентная версия)

Статус: утверждён 2026-08-12. Этап A выполнен, см. «Результаты» в конце.

## Контекст

Ядро и три агента уже работают в Claude Code. Ограничение текущей формы: запуск
возможен только через Claude Code, правки разметки — только через агента, отдать
инструмент коллеге нельзя.

Задача: **автономное приложение**, где три агента живут внутри и ходят в Qwen через
OpenRouter. Открыл, кинул чертёж, нажал «Обработать», поправил номера мышкой,
нажал «Экспорт». Claude Code остаётся только инструментом доработки самой системы.

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Автономность | Полная. Claude Code для работы не нужен |
| Запуск | Сначала localhost в браузере, затем окно приложения (pywebview). `.exe` — потом |
| Модель | `qwen/qwen3.7-plus` — одна на всё. Дорогая `max` отвергнута: вчетверо дороже без выигрыша |
| Фронтенд | Без сборки: HTML + Canvas + чистый JS. Переход на React позже — переписать только UI |

Обе модели принимают изображения, контекст 1 млн токенов. `plus` — $0,32/$1,28 за млн,
`max` — $2/$6. Один чертёж ≈ 11 контактных листов ≈ 20 тыс. входных токенов.
Бюджет ограничителем не является.

## Роль модели

**Модель — глаза и здравый смысл. Код — геометрия и правила.**

| Делает модель | Делает код |
|---------------|-----------|
| Читает надписи с контактных листов | Находит надписи, их координаты и поворот |
| Решает: размер / заголовок вида / штамп / мусор | Считает bbox, ищет свободное место под номер |
| Относит размер к виду в спорных случаях | Привязывает к ближайшему заголовку вида |
| Формулирует технические требования | Присваивает номера и подномера по правилам |
| Перечитывает сомнительное крупным планом | Режет кропы, рисует номера, собирает docx |

Правила остаются теми же файлами `.claude/rules/*.md` — они подмешиваются в системный
промпт Qwen. Правка `numbering.md` меняет поведение и Claude-агентов, и приложения.

## Архитектура

```
karty-obmera/
├─ app/                    # приложение
│  ├─ __main__.py          # python -m app → uvicorn + открыть браузер
│  ├─ server.py            # FastAPI: REST + SSE прогресса
│  ├─ pipeline.py          # оркестратор трёх стадий
│  ├─ llm.py               # OpenRouter: vision, retry, кэш, учёт стоимости  ✅ готов
│  ├─ bench.py             # бенчмарк чтения                                 ✅ готов
│  ├─ agents/{reader,cartographer,reviewer}.py
│  ├─ prompts/*.md         # промпты стадий — правятся текстом
│  ├─ jobs.py              # задания на диске work/<job_id>/
│  └─ web/                 # index.html, app.js, style.css — без сборки
├─ tools/                  # существующее ядро, используется как библиотека
└─ .claude/rules/*.md      # общие правила для агентов и промптов
```

Ядро переиспользуется как есть: `detect_text.detect()`, `detect_frames.find_frames()`,
`crop.cut()` и `make_sheets()`, `render_numbers.render()`, `build_docx.build()`,
`check_markup.check()`, `pdf_to_image.convert()`. Формат обмена — тот же `markup.json`.

### Обязательные приёмы

- **Кэш ответов модели** по хешу «картинка + промпт + модель» — отладка промптов бесплатна
- **Учёт стоимости** — каждое задание показывает потраченные токены и сумму
- **Задание живёт на диске** — приложение можно закрыть и вернуться
- **Стадии перезапускаются по отдельности**
- **Ключ OpenRouter** — в `.env`, в git не попадает

### Экран редактора

Слева — чертёж на Canvas с зумом и панорамированием, красные номера поверх как
перетаскиваемые элементы. Справа — таблица позиций по видам, выделение синхронное.

Действия: перетащить номер, поправить значение, удалить и добавить позицию,
объединить две надписи в одну позицию, сделать подномером, переименовать группу,
перенумеровать всё. Позиции с низкой уверенностью подсвечены, рядом кнопка
«перечитать через max».

## Результаты этапа A

Прогон `qwen/qwen3.7-plus` по 11 контактным листам «Всасывающей головки»:

| Показатель | Значение |
|-----------|----------|
| Надписей на листе | 255 блоков, 11 контактных листов |
| Ответы получены | 255 из 255, ни один лист не потерян |
| **Точность чтения** | **95 %** (61 из 64 проверенных посимвольно) |
| Стоимость чертежа | **$0,027** |
| Токенов | 18 935 входных + 16 246 выходных |

Ошибки модели:

| Эталон | Прочитано | Оценка |
|--------|-----------|--------|
| `1,5×45°` | `15×45°` | **опасная** — потеряна запятая, размер меняется |
| `70°` | пусто | **опасная** — надпись пропущена |
| `3/8"` | `3/8''` | мелочь, лечится словарём в `glossary.md` |

Вывод: порог 90 % пройден, идём по плану. Обе опасные ошибки — ровно тот класс,
который обязан ловить Контролёр повторным чтением крупным планом, поэтому этап E
из необязательного становится критическим.
