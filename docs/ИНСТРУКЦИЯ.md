# Ассистент ОТК — инструкция пользователя

Как получить карту обмера или задание на изготовление из чертежа.

---

## 1. Установка

Нужен **Python 3.11 или новее**. Проверить:

```powershell
python --version
```

Скачать проект и поставить зависимости:

```powershell
git clone https://github.com/ivanovich1071/otk-assistant.git
cd otk-assistant
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 2. Ключ OpenRouter

Ключ нужен **только для сканов** — чертежей без текстового слоя. Векторные PDF
обрабатываются бесплатно и без ключа.

1. Получите ключ на https://openrouter.ai/keys
2. Скопируйте шаблон и впишите ключ:

```powershell
Copy-Item .env.example .env
notepad .env
```

В строке `OPENROUTER_API_KEY=` после знака равенства вставьте ключ, сохраните.

> ⚠️ **Ключ вписывается только в `.env`.** Файл `.env.example` отслеживается git
> и уедет на GitHub вместе с тем, что в нём написано.

## 3. Запуск

### Десктопная версия — обычное приложение

Один раз выполните установку:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт создаст окружение, поставит зависимости и положит на рабочий стол ярлык
**«Ассистент ОТК»**. Дальше приложение запускается двойным щелчком по ярлыку —
открывается своим окном, консоль не нужна.

Только в десктопной версии работает кнопка **«Обзор…»** — системный выбор папки
для сохранения результатов.

### В браузере

```powershell
.venv\Scripts\python.exe -m app
```

Откроется вкладка на `http://127.0.0.1:8765`. Закрыть — `Ctrl+C` в окне команд.
Полезно, когда нужно посмотреть журнал работы или занять другой порт.

## 5. Сценарий: карта обмера по чертежу

**Шаг 1.** Нажмите **«Выбрать чертёж…»** и укажите файл.

Поддерживаются: **PDF, PNG, JPG, JPEG, TIFF, BMP, WebP, GIF**. Сканы —
поддерживаются. Формат DWG или DXF сначала экспортируйте в PDF.

> Если в PDF несколько страниц, карта делается по первой. Остальные листы
> загрузите отдельными заданиями — приложение об этом предупредит.

**Шаг 2.** В списке **«Режим»** выберите **«Карта обмера»**.

**Шаг 3.** Нажмите **«Обработать»**. Задание появится в списке слева.

**Шаг 4.** Следите за вкладкой **«Задание»**. Стадии идут сверху вниз:

| Стадия | Что происходит |
|--------|----------------|
| Подготовка листа | PDF переводится в растр 300 dpi, картинка берётся как есть |
| Поиск надписей | компьютерное зрение находит все надписи и их координаты |
| Контактные листы | надписи собираются в листы по 24 штуки для чтения |
| Чтение и разметка | модель читает надписи, код разбивает по видам и нумерует |
| Нумерация | красные номера наносятся на чертёж |
| Карта обмера | собирается таблица в Word |
| Проверка | ищутся дубли, разрывы нумерации, неразобранные блоки |

Время обработки идёт вживую в строке «Время обработки». Векторный чертёж —
секунды, скан — несколько минут (модель читает контактные листы по очереди).

**Шаг 5.** Откройте вкладку **«Чертёж»** и проверьте номера.

- `+` и `−` — масштаб, **«По ширине»** и **«100 %»** — быстрые режимы
- тянуть мышью — панорамирование

**Шаг 6.** Откройте вкладку **«Карта обмера»** и вычитайте таблицу.

- значения правятся прямо в полях;
- **жёлтым подсвечены позиции, в которых система не уверена** — их смотрите
  в первую очередь, сверяя с чертежом на соседней вкладке;
- кнопка `×` убирает лишнюю позицию (в карту попадают штампы, таблицы
  параметров, обрывки техтребований — на сканах это бывает);
- убранная позиция перечёркивается, повторное нажатие возвращает её.

**Шаг 7.** Нажмите **«Сохранить правки»**.

Удалённые позиции выбрасываются, **нумерация пересчитывается заново сквозь все
группы**, чтобы не осталось дыр.

**Шаг 8.** Нажмите **«Пересобрать чертёж и карту»**.

Красные номера наносятся заново, документ Word собирается заново. Модель при
этом не вызывается — пересборка занимает меньше секунды и ничего не стоит.

**Шаг 9.** Вкладка **«Файлы»** — заберите результат.

- **открыть** — посмотреть файл в новой вкладке
- **скачать** — сохранить на диск

## 6. Сценарий: требования по изготовлению

**Шаг 1.** Выберите **сводный PDF комплекта** — один файл, в котором идут
сборочный чертёж, спецификации, подсборки и детали.

> Режим работает **только с векторным PDF** — где есть текстовый слой.
> Если подать скан, задание остановится и предложит переключиться на карту
> обмера. Проверить просто: если в PDF текст выделяется мышью — он векторный.

**Шаг 2.** Режим — **«Требования по изготовлению»**, нажмите **«Обработать»**.

**Шаг 3.** Четыре стадии проходят за секунды:

| Стадия | Что происходит |
|--------|----------------|
| Чтение PDF | из текстового слоя берутся штампы, техтребования, спецификации |
| Дерево комплекта | по спецификациям строится состав изделия |
| Канон и общие данные | формулировки приводятся к привычному виду, модель пишет раздел «Общие данные» |
| Документ | собирается `.docx` |

**Шаг 4.** Обязательно прочитайте **«Замечания»** на вкладке «Задание».

Там то, что система не стала решать за вас:

- расхождение массы между штампом детали и спецификацией;
- деталь есть в спецификации, а чертежа в комплекте нет;
- лист, не найденный ни в одной спецификации.

**Шаг 5.** Вкладка **«Файлы»** — откройте или скачайте документ.

---

## 7. Папка для сохранения

Вкладка **«Файлы»**, строка сверху:

- впишите путь и нажмите **«Применить»** — туда будут складываться результаты
  всех новых заданий;
- **«Обзор…»** открывает системный выбор папки — работает в оконной версии
  (`--desktop`), в браузере кнопка неактивна;
- **«Сохранить сюда файлы задания»** копирует готовые файлы текущего задания
  в выбранную папку.

Текущая папка всегда видна в строке состояния внизу.

## 8. Кнопки управления заданиями

| Кнопка | Что делает |
|--------|-----------|
| **Повторить** | прогоняет задание заново. Ответы модели берутся из кэша, поэтому бесплатно и быстро |
| **Удалить** | убирает одно задание |
| **Очистить список** | убирает все завершённые задания. Идущее в работе не трогает, **готовые файлы в папке результатов остаются** |

Задания хранятся на диске в `work/jobs/`. Приложение можно закрыть и вернуться —
список и результаты на месте.

## 9. Если что-то пошло не так

| Симптом | Причина и что делать |
|---------|---------------------|
| «Режим ТЗ работает только с векторным PDF…» | подан скан. Переключите режим на «Карта обмера» |
| «ключ OpenRouter: не задан» в правом верхнем углу | ключ не найден. Проверьте, что он в `.env`, а не в `.env.example`, и перезапустите приложение |
| Задание висит на «Чтение и разметка» | модель читает контактные листы, на скане это несколько минут. Время видно в карточке |
| В карте много лишних строк | обычное дело для сканов: в разметку попали штамп и таблицы. Уберите их кнопкой `×` и пересоберите |
| Потерялся знак `Ø` в значении | известное ограничение чтения рукописных чертежей. Впишите знак руками в таблице |
| Порт 8765 занят | запустите с другим портом: `python -m app --port 8800` |

## 10. Настройка под свои правила без программирования

Четыре файла в `.claude/rules/` правятся обычным текстом, код трогать не нужно:

| Файл | За что отвечает |
|------|-----------------|
| `numbering.md` | порядок групп и позиций, названия видов по ГОСТ 2.305, подномера |
| `glossary.md` | как писать `Ø`, `°`, `×`, поля допусков, раскрытие сокращений |
| `tt-rules.md` | какие технические требования переносить в карту обмера |
| `tz-format.md` | структура задания на изготовление, канон формулировок |

Промпты к модели лежат в `app/prompts/` и тоже правятся текстом.

Внешний вид приложения — `app/web/style.css`.
