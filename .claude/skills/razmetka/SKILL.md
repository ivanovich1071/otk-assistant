# Разметка чертежа

Запускает одного Разметчика — когда нужен только размеченный чертёж
или когда карту в Word будете собирать отдельно.

## Порядок

1. Определи файл чертежа: названный явно, иначе из `input/`.
   PDF сначала переведи в растр: `tools/pdf_to_image.py`.

2. Запусти агента `markup-agent`:

   > Размети чертёж `input/<имя>.<ext>` по `.claude/agents/markup-agent.md`.
   > Результат: `work/markup.json` и `output/<имя> (карта обмера).jpg`.

3. Проверь формально:

   ```
   .venv/Scripts/python.exe tools/check_markup.py work/markup.json --blocks work/blocks.json
   ```

4. Покажи размеченный JPG через `SendUserFile` и назови: число групп, число
   позиций, позиции с низкой уверенностью.

## Правка вручную

Если номер сел неудачно, задай ему координаты в `work/markup.json`
(`label_x`, `label_y`) и перерисуй:

```
.venv/Scripts/python.exe tools/render_numbers.py "input/<имя>.<ext>" work/markup.json -o "output/<имя> (карта обмера).jpg"
```

Разметка сохранена — карту в Word из неё можно собрать потом скиллом `karta-word`.
