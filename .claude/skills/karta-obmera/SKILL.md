# Карта обмера — общий сценарий

Правила зон листа — `.claude/rules/sheet-zones.md`: что относится к чертежу,
что к штампу, спецификации и текстовой части, и что из этого не попадает
в карту. Спецификация не попадает совсем.

Три агента подряд: **Разметчик → Картограф → Контролёр**.
На входе чертёж (JPG/TIF/PNG/PDF), на выходе — размеченный JPG, карта обмера в Word
и отчёт проверки.

## 0. Подготовка

Определи чертежи для обработки:
- назван конкретный файл — работай с ним
- названа папка или ничего не названо — возьми всё из `input/`
- несколько файлов — обрабатывай **строго последовательно**, каждый до конца

Для каждого чертежа заведи рабочее имя `<имя>` = имя файла без расширения.
Если файл лежит вне проекта, скопируй его в `input/`.

PDF конвертируй в растр перед разметкой:

```
.venv/Scripts/python.exe tools/pdf_to_image.py "input/<имя>.pdf" -o "input/<имя>.png"
```

Если PDF векторный (инструмент об этом скажет), он всё равно даёт растр —
разметка идёт по нему, а PDF на выходе собирается из того же растра.

## 1. Разметчик

Запусти агента `markup-agent` с задачей:

> Размети чертёж `input/<имя>.<ext>`. Следуй `.claude/agents/markup-agent.md`.
> Результат: `work/markup.json` и `output/<имя> (карта обмера).jpg`.

Дождись отчёта. Проверь формальные ошибки:

```
.venv/Scripts/python.exe tools/check_markup.py work/markup.json --blocks work/blocks.json
```

Если есть замечания — верни их Разметчику через `SendMessage` и дождись исправления.

Покажи пользователю размеченный JPG через `SendUserFile`.

## 2. Картограф

Запусти агента `docx-agent`:

> Собери карту обмера из `work/markup.json` по `.claude/agents/docx-agent.md`.
> Чертёж: `input/<имя>.<ext>`. Результат: `output/<имя> (карта обмера).docx`.

## 3. Контролёр

Запусти агента `review-agent`:

> Проверь карту обмера по `.claude/agents/review-agent.md`.
> Чертёж `input/<имя>.<ext>`, разметка `work/markup.json`,
> JPG `output/<имя> (карта обмера).jpg`, карта `output/<имя> (карта обмера).docx`.
> Отчёт: `output/review.md`. Правки без моего подтверждения не вноси.

## 4. Сводка пользователю

Коротко и по делу:

- обозначение и наименование детали
- сколько групп и позиций в карте
- сколько замечаний у Контролёра и какие — самые существенные
- пути к файлам

Замечания Контролёра покажи списком и спроси, какие исправлять. После
подтверждения передай их Контролёру через `SendMessage` — он правит `markup.json`
и перегенерирует JPG и docx.

При пакетной обработке сводку давай по каждому чертежу, в конце — общий итог.

## Что важно

- Карта обмера — приёмочный документ. Лучше отдать честный список сомнительных
  позиций, чем красивую карту с выдуманным размером.
- Колонки «Фактические значения» всегда остаются пустыми — их заполняет метролог.
- Рамки допусков формы и расположения переносятся картинкой, а не текстом.
