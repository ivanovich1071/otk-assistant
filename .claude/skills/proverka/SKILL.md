# Проверка карты обмера

Запускает Контролёра поверх готового комплекта.

## Порядок

1. Собери входные файлы: чертёж, `work/markup.json`, размеченный JPG, docx.
   Если чего-то нет — скажи об этом и проверь то, что есть.

2. Формальная проверка перед агентом:

   ```
   .venv/Scripts/python.exe tools/check_markup.py work/markup.json --blocks work/blocks.json
   ```

3. Запусти агента `review-agent`:

   > Проверь карту обмера по `.claude/agents/review-agent.md`.
   > Чертёж `<путь>`, разметка `work/markup.json`,
   > JPG `output/<имя> (карта обмера).jpg`, карта `output/<имя> (карта обмера).docx`.
   > Отчёт: `output/review.md`. Правки без подтверждения не вноси.

4. Покажи пользователю замечания списком, самое существенное — первым.
   Спроси, какие исправлять.

5. После подтверждения передай список Контролёру через `SendMessage`.
   Он правит `markup.json` и перегенерирует JPG и docx.

## Отдельная сверка с эталоном

Если карта делалась по детали из `tests/gold/`:

```
.venv/Scripts/python.exe tools/compare_gold.py --card "output/<имя> (карта обмера).docx" --gold "tests/gold/<обозначение>/card.docx" --quiet
```

Это даёт числа: сколько позиций совпало по номеру и сколько по значению.
