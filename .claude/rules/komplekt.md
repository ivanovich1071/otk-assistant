# Комплект чертежей

Один PDF часто содержит не чертёж, а весь комплект: сборочный чертёж, листы
спецификации и чертежи деталей. В архиве `Documents\ПТС` таких файлов 136
из 542, медиана — 8 листов, максимум 67.

Карта обмера делается **по одному листу**. Комплект — это не один большой
чертёж, а список листов, из которых часть идёт в работу, а часть нет.

## Порядок

1. **Разбор комплекта** — по каждому листу определяются формат, тип,
   обозначение и наименование. Считать при этом ничего нельзя: сорок листов
   это часы работы и доллары, и запускать их без ведома человека нельзя.
2. **Выбор листов** — человек отмечает нужные в оглавлении. Предложенное
   по умолчанию — чертежи, кроме продолжений.
3. **Задания по листам** — каждый отмеченный лист становится отдельным
   заданием со своей картой обмера. Считаются они по очереди, а не разом.

## Тип листа

| Тип | Признак | В работу |
|-----|---------|----------|
| **Спецификация** | лист A4, и зона таблицы занимает больше 0,6 высоты рамки. У векторного PDF — по шапке «Формат / Зона / Поз. / Обозначение / Наименование / Кол.» | **нет**, никогда: содержимое спецификации в карту не идёт совсем (`sheet-zones.md`) |
| **Чертёж** | всё остальное | да |
| **Продолжение** | графа «Лист» больше единицы, либо это обозначение уже встречалось в файле раньше | по умолчанию нет, но галочку можно поставить вручную |

Спецификацию по ГОСТ 2.106 выполняют только на A4 — поэтому крупные листы
растром не разбираются вовсе. Это экономит по 25 секунд на каждом листе A0.

## Штамп листа

Основная надпись берётся **вырезкой прямо из PDF** по ГОСТ 2.104: 185×55 мм
в правом нижнем углу листа, отступ 5 мм, запас 10 мм на перекос скана. Целый
лист ради штампа рендерить не надо — на A0 это 16 секунд против доли секунды.

Из штампа для оглавления нужны обозначение, наименование и графы «Лист»
и «Листов»: без них многолистовой документ не отличить от нескольких разных.

## Что нельзя

- **Считать без спроса.** После загрузки комплекта не делается ни одной карты,
  пока человек не отметил листы и не нажал кнопку. Оценка времени и денег
  показывается до старта, а не после.
- **Копировать исходник в каждое задание.** Лист берётся из PDF родителя
  по номеру страницы: сорок копий файла на 17 МБ — это 700 МБ на один комплект.
- **Считать листы разом.** Конвейер упирается в процессор, поэтому листы идут
  по очереди, и очередь можно прервать. Уже готовые листы при этом остаются.
