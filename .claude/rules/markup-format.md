# Формат `work/markup.json`

Единый контракт между тремя агентами. Разметчик его создаёт, Картограф читает,
Контролёр правит.

```json
{
  "drawing": "C:/.../input/деталь.jpg",
  "designation": "5489.0123.0000.28",
  "title": "Всасывающая головка",
  "text_height": 20.0,
  "groups": [
    {
      "name": "Главный вид",
      "items": [
        {
          "no": "1",
          "value": "Ø329",
          "kind": "text",
          "block": 12,
          "x": 240, "y": 430, "w": 26, "h": 96,
          "label_x": null, "label_y": null,
          "confidence": "high"
        },
        {
          "no": "8-1",
          "value": "",
          "kind": "frame",
          "frame": 4,
          "x": 973, "y": 1130, "w": 184, "h": 59,
          "confidence": "high"
        }
      ]
    }
  ],
  "tech_requirements": [
    { "no": "8", "text": "На поверхностях К, Л, М не допускаются: ..." },
    { "no": "",  "text": "Материал – Чугун ЧН15Д3Ш. Предоставить сертификат по химсоставу" }
  ],
  "skipped": [
    { "block": 77, "reason": "штамп" }
  ]
}
```

## Поля

| Поле | Значение |
|------|----------|
| `drawing` | абсолютный путь к исходному чертежу |
| `designation` / `title` | обозначение и наименование из штампа |
| `text_height` | из `blocks.json`, нужен для масштаба номеров |
| `groups[].name` | заголовок группы ровно как в карте: `Главный вид`, `Вид А`, `Вид справа`, `Вид слева`, `Разрез Ж-Ж`, `Выноска Г` |
| `items[].no` | номер позиции: `12` или `24-3` |
| `items[].value` | значение **как на чертеже**, после словаря `glossary.md` |
| `items[].kind` | `text` — обычная надпись, `frame` — рамка допуска (в Word пойдёт картинкой) |
| `items[].block` / `frame` | id из `blocks.json` / `frames.json` — для трассировки |
| `x,y,w,h` | bbox на чертеже; для `frame` — bbox рамки целиком |
| `label_x,label_y` | куда поставлен номер; `null` — выбрать автоматически |
| `confidence` | `high` / `low`; `low` обязательно перепроверяет Контролёр |
| `skipped` | блоки, сознательно не попавшие в карту, с причиной — чтобы Контролёр не искал их заново |

## Правила

- Порядок `groups` и `items` внутри группы = порядок номеров в карте. Сортировать при
  выводе нельзя — порядок уже задан Разметчиком.
- Один размер = одна позиция. Если на чертеже надпись разбита на два блока
  (`R8` и `4 радиуса`), они объединяются в одну позицию с `value` = `R8 4 радиуса`,
  а bbox берётся по основному блоку.
- `tech_requirements` переносятся не все — см. `tt-rules.md`.
