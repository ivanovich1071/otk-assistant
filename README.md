# Карты обмера — агентская система

Заменяет ручную работу: разметку размеров в Photoshop и перенос в Word.
На входе чертёж, на выходе — размеченный JPG и карта обмера в Word.

## Как пользоваться

Открыть Claude Code в этой папке, положить чертежи в `input/` и сказать:

```
/karta-obmera
```

или назвать файл: `/karta-obmera input/5489.0123.0000.28.jpg`

Дальше система сделает три шага сама:

1. **Разметчик** прочитает все надписи, разберёт их по видам и разрезам,
   пронумерует и нанесёт красные номера на чертёж
2. **Картограф** соберёт карту обмера в Word по шаблону предприятия
3. **Контролёр** сверит всё с чертежом и выдаст список замечаний

Результат — в `output/`.

### Отдельные шаги

| Команда | Что делает |
|---------|-----------|
| `/razmetka` | только нанести нумерацию на чертёж |
| `/karta-word` | собрать Word из готовой разметки `work/markup.json` |
| `/proverka` | проверить готовую карту |

## Установка

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Чтобы вызывать скиллы из любой папки (например, прямо из `Documents\ПТС\<заказ>`):

```powershell
Copy-Item -Recurse -Force .claude\skills\* $HOME\.claude\skills\
Copy-Item -Recurse -Force .claude\agents\* $HOME\.claude\agents\
```

## Настройка без программирования

Три файла правил в `.claude/rules/` — их можно править текстом, код трогать не нужно:

| Файл | За что отвечает |
|------|-----------------|
| `numbering.md` | порядок групп и позиций, правила подномеров `N-1` |
| `glossary.md` | как писать `Ø`, `°`, `´´`, `×`, допуски, раскрытие сокращений |
| `tt-rules.md` | какие технические требования переносить в карту |

## Инструменты

Вся геометрия считается кодом, агенты только читают и решают.

| Скрипт | Назначение |
|--------|-----------|
| `tools/detect_text.py` | находит все надписи чертежа с точными координатами и поворотом |
| `tools/detect_frames.py` | находит рамки допусков формы и расположения |
| `tools/crop.py` | контактные листы для чтения и кропы для вставки в Word |
| `tools/render_numbers.py` | наносит красные номера в свободные места |
| `tools/build_docx.py` | собирает карту по шаблону `templates/karta_obmera.docx` |
| `tools/check_markup.py` | формальная проверка разметки: дубли, разрывы, пустые значения |
| `tools/compare_gold.py` | печать карты и сверка с эталоном |
| `tools/pdf_to_image.py` | PDF → растр, заодно говорит, скан это или вектор |

## Проверка на эталоне

В `tests/gold/` лежат реальные пары «чертёж / карта». Прогон ядра
на `5489.0123.0000.28`:

```powershell
.venv\Scripts\python.exe tools\compare_gold.py --card "output\5489.0123.0000.28 Всасывающая головка (карта обмера).docx" --gold "tests\gold\5489.0123.0000.28\card.docx" --quiet
```

Результат первого прогона: 59 позиций из 61, значения совпали в 82 % случаев.
Часть расхождений — там, где система права, а ручная карта содержит опечатку
(`1*45°` вместо `1×45°`, `Ø440` вместо `Ø470` на чертеже).
